Whole-macroblock explicit weighting (WeightUniMB / WeightBiMB) against the per-block calls and
against FFmpeg 6.1.1, AMD Ryzen 9 7950X (Zen 4), one core (taskset -c 9), 1-minute load 0.3 to 0.9.

Why cycles: wall time on this host swung by 1.5x within minutes (another session's load on the
neighbouring cores changes the clock: the same binary measured 11.8, 13.3 and 17.5 ns per macroblock
in one hour). CPU cycles in user space (perf stat -e cycles:u) do not move with the clock. Per
macroblock = (cycles at 800 iterations - cycles at 200 iterations) / 600 / 8160 macroblocks.
